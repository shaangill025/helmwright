# Owner decisions

Decisions the owner made for helmwright, with the options that were rejected. Design references
(`03§`, `06§`, …) point to the Meta-Harness Design v2 sections; "Sept" is the September 2026
requirements document. This log is a stopgap until the decision ledger (Slice A) exists.

## Slice B (2026-10-06)

| Q                         | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | Rejected                                                   |

| Q26 storage               | `node:sqlite`; append-only enforced in the store; object change and its event in one transaction; database file in a gitignored state directory                                                                                                                                                                                                                                                                                                                                                                                 | better-sqlite3; append-only JSONL                          |
| Q6 actions                | The full September action set mapped onto the seven kinds: dispatch/move → Task, commit → Artifact, promote → Skill, resolve → Decision, merge → Rule, edit → Rule/Skill, spawn/cancel/join → Run; plus edit/execute/validate on Artifact and the September transition state machine (requested → authorized → executing → succeeded / failed / outcome-unknown; denied; cancelled). Actions without an M1 caller get schemas, permissions and transition tests now and handlers in their milestone (spawn/join M4, promote M3) | add the September kinds; minimal M1 set; shell filter      |
| Q51 config                | `helmwright.config.json` validated by its own schema; Ring 0 settings (08) are always-ask to change; a non-default alternative is rejected until it has a fixture (07 rule 1).
