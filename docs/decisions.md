# Owner decisions

Decisions the owner made for helmwright, with the options that were rejected. Design references
(`03§`, `06§`, …) point to the Meta-Harness Design v2 sections; "Sept" is the September 2026
requirements document. This log is a stopgap until the decision ledger (Slice A) exists.

| Q6 actions                | The September action set mapped onto the seven kinds: dispatch/move → Task, commit → Artifact, promote → Skill, resolve → Decision (card), merge(allowlist entry) → Rule (owner-only; not PR merging), edit → Rule/Skill, spawn/cancel/join → Run; plus edit/execute/validate on Artifact and the September transition state machine (requested → authorized → executing → succeeded / failed / outcome-unknown; denied; cancelled). Deploy and publish stay always-ask permission actions.
